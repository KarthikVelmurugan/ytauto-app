Privacy policy

ytauto · last updated 29 October 2026

ytauto is a personal desktop application used only by its owner to manage and publish videos on YouTube channels that he owns. It is not offered to the public. This policy explains what data it accesses and how that data is handled.

Data the app accesses

  • Basic information about the owner's own YouTube channels (channel id, title, branding settings).
  • The owner's own videos, playlists, captions, thumbnails and comments on those videos, in order to upload, schedule, update and manage them.
  • YouTube Analytics reports for the owner's own channels (views, watch time, audience retention and similar aggregated metrics).
  • Files in Google Drive that the app itself created (the drive.file scope); it cannot see any other Drive files.

How the data is used

The data is used only to provide the app's functions to its owner: publishing his videos, scheduling them, and reviewing their performance to improve future videos. It is not used for advertising, profiling, or any purpose unrelated to managing the owner's own channels.

Storage and security

All data stays on the owner's own computer. OAuth tokens are stored locally and encrypted with Windows Data Protection (DPAPI). Analytics figures are kept in a local database. There is no server, no account system, and no transfer of data to any third party.

Sharing

The app does not sell, share, or transfer Google user data to anyone. No humans other than the owner read the data.

Google API Services User Data Policy

ytauto's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Retention and deletion

Data is kept only as long as the owner uses the app. Access can be revoked at any time at myaccount.google.com/permissions; the owner can delete the local token files and database at any time, which removes all stored data.
