ytauto

A private publishing tool for the owner's own YouTube channels.

ytauto is a personal desktop application run by a single individual on his own computer. It prepares original educational videos (history, military and aviation history, and astronomy) and publishes them to YouTube channels that he owns, using the YouTube Data API.

What it does with Google APIs

  • YouTube Data API: uploads the owner's videos, sets titles, descriptions, thumbnails, captions and playlists, schedules publication, and posts or pins comments on the owner's own videos.
  • YouTube Analytics API: reads performance reports for the owner's own channels so future videos can be improved.
  • Google Drive API (drive.file): stores archive copies of the videos the app itself created in the owner's Drive. It cannot see any other files.

The app is not offered to the public and has no other users.
